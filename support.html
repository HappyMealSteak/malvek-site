Support

Malvek for iPhone

Email support@malvekconnect.com and you will get a reply from a person. There is no ticket system and no account to log into — the same reason the app has no backend.

Before you write in

A few things come up often enough to answer here.

The keyboard has no Ctrl, Esc, or arrow keys

It does — iOS's own keyboard doesn't provide them, so Malvek adds its own row directly above it while you're connected. Ctrl, Esc, Tab, the arrows, Ctrl+C, Ctrl+D, Ctrl+Z, Ctrl+L, Home, End, Page Up and Page Down are all there; scroll the row sideways for the rest. Tap ctrl and then a letter to send any other control code.

It asks me to verify a host key

That is deliberate, and it is the same thing the ssh command does the first time you connect to a machine. Malvek shows the server's fingerprint and remembers it. If that fingerprint ever changes you will get a red warning, because a changed key can mean the connection is being intercepted.

"Could not agree on an encryption algorithm"

The server is offering only ciphers Malvek cannot negotiate. Enabling AES-GCM or AES-CTR on the server side resolves it. Malvek does not support chacha20-poly1305.

Can I get my keys back if I lose my phone?

No, and that is the trade. Malvek has no server, so a key generated on your device exists only there — nobody, including us, can restore it. Keep a copy of anything you cannot afford to lose on a machine you control. See the privacy policy for the whole picture.

What does the purchase actually unlock?

The number of hosts you can save, and nothing else. Three are free. The terminal, SFTP, saved scripts, and SSH key generation and import all work without paying. It is one payment, not a subscription.

Reporting a bug

Email the address above with the iPhone model, the iOS version, and what you were doing. If it involves a connection failure, the exact message Malvek printed is the most useful thing you can include.

Security issues

Email security@malvekconnect.com rather than filing anything public, and please allow time for a fix before disclosing.
